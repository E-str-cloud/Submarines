# משחק צוללות

משחק צוללות (Battleship) קלאסי נגד המחשב, כתוב ב-HTML, CSS ו-JavaScript בלבד, בלי ספריות ובלי שלב build.

## איך משחקים

1. פותחים את `index.html` בדפדפן.
2. אם רוצים סידור אחר לצי, לוחצים על "ערבב את הצי שלי" לפני הירייה הראשונה.
3. לוחצים על משבצת בלוח היריב כדי לירות. אחרי כל ירייה המחשב יורה בחזרה.
4. הראשון שמטביע את כל חמש הצוללות של הצד השני מנצח.

## מבנה הפרויקט

| קובץ | תפקיד |
| --- | --- |
| `index.html` | מבנה הדף |
| `style.css` | עיצוב |
| `script.js` | לוגיקת המשחק והמחשב היריב |

## רעיונות לתרגול בגיטהאב

- הצבה ידנית של הצוללות בגרירה
- טבלת ניקוד שנשמרת ב-`localStorage`
- רמות קושי למחשב
- צלילים לפגיעה ולהחטאה
